## Границы синонимов и терминов

Допустимый синоним подходит только тогда, когда сохраняет исходный смысл в конкретном контексте; если контекст уже, называйте конкретный объект. «Внешний TUN» обозначает предоставленный хостом интерфейс или объект интеграции. «Дескриптор TUN» уместен только при описании именно дескриптора, передаваемого API. Эти выражения не взаимозаменяемы во всех разделах. «FFI» шире, чем «C ABI», а «SDK» означает набор артефактов, состав которого нужно уточнять по релизу.

## Точные имена, которые не переводят

Сохраняйте написание имён протоколов, API и идентификаторов: `VLESS`, `REALITY`, `XTLS Vision`, `XUDP`, `TUN`, `SOCKS5`, `C ABI`, `FFI`, `SDK`, `DoH`, `DoT`, `DoQ`, `Xray-core`, `sing-box`, `rc_validate`, `rc_is_alive`, `dns.bootstrap`, `route.final`, `user_id`. Для дополнительных имён сверяйтесь с исходниками и публичными заголовками.

Используйте слово «VPN» только для сценария, где действительно обрабатывается VPN-трафик, например TUN. Для локального SOCKS/HTTP-прокси и библиотеки называйте конкретный компонент или режим.
