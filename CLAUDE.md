# Правила для Claude Code

- В сообщениях коммитов, описаниях PR, комментариях на GitHub и в файлах
  репозитория — никаких ссылок на сессии Claude (`claude.ai/code/session_…`)
  и строк `Claude-Session:`.
- В описаниях PR и комментариях — без строки «🤖 Generated with Claude
  Code» и подобных подписей.
